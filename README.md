# Osembo School app
1. Upload ALL files/folders in this project to a new GitHub repo (keep the .github folder).
2. Open the repo > Actions tab > "Build Osembo apps" runs by itself (or click Run workflow).
3. When both jobs are green, open the run and download:
   - Osembo-Windows (installer .exe + portable .exe)
   - Osembo-Android (app-debug.apk)
